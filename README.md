# 🐚 holbertonschool-shell

Scripts et exercices du module **Shell** du cursus Holberton School : maîtriser le terminal Linux, les scripts Bash, les redirections, les permissions et les variables.

## 📚 Sommaire

| Dossier | Thème | Tâches |
|---|---|---|
| [`basics/`](./basics) | Navigation, fichiers, répertoires, liens symboliques, `ls`, `cp`, `mv`, `rm`, `tree` | 0 → 17 |
| [`init_files_variables_and_expansions/`](./init_files_variables_and_expansions) | Alias, `PATH`, variables locales/globales, expansions arithmétiques, conversions de bases | 0 → 14 |
| [`io_redirections_and_filters/`](./io_redirections_and_filters) | Redirections, pipes, `head`, `tail`, `grep`, `sort`, `uniq`, `tr`, `find`, `rev` | 0 → 22 |
| [`permissions/`](./permissions) | `chmod`, `chown`, `chgrp`, `su`, groupes, permissions symboliques et octales | 0 → 16 |

Chaque dossier contient son propre `README.md` avec le détail des exercices.

## 🧰 Environnement

- OS : Ubuntu 20.04 LTS
- Shell : Bash
- Chaque script commence par `#!/bin/bash` et finit par une nouvelle ligne
- Les scripts sont exécutables (`chmod u+x <fichier>`)

## 🚀 Utilisation

```bash
git clone https://github.com/limogesgaby-bit/holbertonschool-shell.git
cd holbertonschool-shell/basics
chmod u+x 0-current_working_directory
./0-current_working_directory
```

## 🎯 Compétences travaillées

- Naviguer et manipuler le système de fichiers en ligne de commande
- Chaîner des commandes avec pipes et redirections (`>`, `>>`, `<`, `|`)
- Utiliser variables d'environnement, alias et expansions
- Gérer utilisateurs, groupes et permissions
- Écrire des scripts Bash courts, lisibles et respectant les contraintes Holberton
